# grant

## Быстрый запуск

```
cd grant/docker
docker compose up -d
```

## Адреса

```
Адрес приложения -> 127.0.0.1:8088
```

## Команды для разработчиков

```
ВАЖНО: Makefile лежит в директории grant/docker. Отсюда и нужно выполнять следующие команды:


// DEVELOPMENT - Локальная база данных
// ВАЖНО!!! Когда вы используете этот режим, то ваша база данных пуста. Чтобы заполнить ее информацией, то воспользуйтесь консолью psql
// Для входа в psql вам нужно прописать:

make dev-start ---- Запуск всех сервисов для разработки в фоновом режиме
make dev-stop --- Остановка и удаление всех контейнеров разработки
make dev-update-all ---- Полное обновление всей среды разработки (Останавливает контейнеры, Удаляет образ приложения, Пересобирает и запускает всё заново)
make dev-check --- Проверка статуса всех контейнеров разработки
make dev-update-app --- Обновление только приложения (Пересобирает контейнер приложения)
make dev-update-front --- Обновление фронтенда (Nginx) (Перезапускает nginx контейнер, Применяет изменения в статических файлах)

// Production - База данных с уже готовыми данными
Все тоже самое, но везде приписка prod, а не dev. Пример: make prod-start

```
