# Reportify

Это веб-платформа, которая позволяет создавать профессиональные отчеты и визуализации без необходимости писать SQL-запросы.

## 📘 О проекте

Сервис предоставляет:

- Авторизацию и выпуск **JWT-токенов**
- Получение **метаданных БД** (схемы / таблицы / колонки)
- Работа с **пользовательским кэшем SQL-запросов**
- Генерация **отчётов в разных форматах**

## Архитектура:

HTTP handlers (Gin) → services (бизнес-логика) → repositories (PG/Redis) → storage

## 📜 API (Swagger)

**BasePath:** `/api/v1`
**Безопасность:** `BearerAuth` (`Authorization: Bearer <JWT>`)

### 🔐 Auth

| Метод | Путь           | Описание                                                   |
| ---------- | ------------------ | ------------------------------------------------------------------ |
| `POST`   | `/secure/auth`   | Авторизация пользователя                    |
| `GET`    | `/secure/access` | Обновление access-токена по refresh-токену |

### 🗄 Metadata

| Метод | Путь        | Описание                                                                            |
| ---------- | --------------- | ------------------------------------------------------------------------------------------- |
| `GET`    | `/db/schemas` | Получить список схем БД                                                 |
| `GET`    | `/db/tables`  | Получить таблицы в схеме (`schema` — query)                         |
| `GET`    | `/db/columns` | Получить колонки таблицы (`schema`, `table` — query)             |
| `GET`    | `/cache`      | Получить сохранённые запросы пользователя             |
| `DELETE` | `/cache`      | Очистить историю кэша пользователя*(опционально)* |

### 📊 Report

| Метод | Путь              | Описание                                                 |
| ---------- | --------------------- | ---------------------------------------------------------------- |
| `POST`   | `/reports/{format}` | Создать отчёт (`pdf`, `csv`, `docx`, `json`) |

**Swagger UI:**

- Через gin-swagger: `http://<host>:<port>/swagger/index.html`
- Через nginx: `http://<host>/docs/`

## Структура проекта

```
cmd/
  main.go                # Точка входа

internal/
  web/                   # HTTP слой (Gin)
    server.go            # Инициализация роутера/сервера
    endpoints.go         # Константы путей
    middleware/          # Логирование, JWT-проверки
    handlers/
      auth_*             # Авторизация
      metadata_*         # /db/* и /cache
      report_*           # /reports/{format}

  service/               # Бизнес-логика
    metadata_*           # Метаданные БД
    report_*             # Отчёты
    user_*               # Пользователи

  repository/            # Доступ к данным (PG/Redis)
    report_*             # SQL-скрипты
    user_*               # CRUD-пользователи

  secure/                # JWT и хеширование
  cache/                 # Кэш
  models/                # DTO-модели запросов/ответов
  config/                # Конфиги и валидация env
  logger/                # Логирование
  convert/               # Генерация PDF/Docx/CSV
  di/                    # Инициализация зависимостей

docker/
  Dockerfile             # Сборка приложения
  dev/docker-compose-dev.yaml
  prod/docker-compose-prod.yaml
  assets/db/...          # Миграции
  nginx/...              # Конфиги и статика nginx

logs/
  ...                    # Логи приложения

```
